# Publication boundary

This repository is a hand-curated showcase, not a mirror of the private working
project (`Zeeekrom/tasmania-student-notes`, private). It shares no Git history
with it.

## Included

- A project account in English and Simplified Chinese, kept in step.
- Screenshots of the public Azure preview only, and a poster made from them.
- A high-level description of the newsroom and its decision rules.
- Dated checks, each stated with what it does and does not show.
- Licence texts for the third-party work visible in the images.

## Excluded

- Website, newsroom and deployment source code.
- Drafts, student submissions and private editorial decisions.
- Prompts, agent instructions, agent logs and raw recordings.
- Screenshots of the board, Slack or any private view.
- Names and contact details of people other than the project owner.
- Credentials, tokens, account identifiers and machine paths.

## Release check

1. Every claim describes something verified on the stated date. Simulated,
   replayed, piloted and planned work stay clearly apart.
2. Each image is inspected for private information and for a misleading status.
3. The staged file list, links and image metadata are reviewed, and a scan for
   secrets and personal data is run.
4. Third-party notices are kept for any newly visible third-party work.
5. The project owner approves the push. Nothing in this repository is published
   automatically.
